Step 2.2 — Implement graph engine

Create:

Implement:

last_seen

No deletes.
Only create or extend time windows.

PHASE 3 — Dataset Generator (Critical) (20 minutes)
Step 3.1 — Add generator

Create:

backend/app/model/dataset_gen.py


Must support:

deterministic seed

multiple scenarios

NDJSON output

correlation IDs

large file streaming

Test quickly:

python backend/app/model/dataset_gen.py \
  --seed 42 \
  --scenario cicd_compromise \
  --days 1 \
  --out examples/cicd.ndjson

Step 3.2 — Replay logic

Add endpoint:

POST /events/replay


Replay flow:

Read NDJSON

Sort by timestamp

Apply U(G, e)

Serialize graph canonically

Compute SHA256 → graph_hash

This hash is your reproducibility proof.

PHASE 4 — Determinism Tests (15 minutes)
Step 4.1 — Tests

Create tests:

backend/app/tests/test_replay.py


Assertions:

replay same file twice → same hash

replay shuffled events → same hash

Run:

pytest backend/app/tests


Do not proceed until tests pass.
